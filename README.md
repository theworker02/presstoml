# presstoml

Press digests and toml fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/presstoml/

## Install / run

```bash
git clone https://github.com/theworker02/presstoml.git
cd presstoml
node src/cli.js
node --test
```
